Comceptos básicos sobre estructuras

Una estructura es una colección de una o más variables, de tipos posiblemente deifernetes, agrupadas bajo un solo nombre para manejo coveniente. Las estructuras ayudan a organizar datos complicados, en particular dentro de programas grandes, debido a que perimten que a un grupo de variables relacionadas se les trate como una unidad en lugar de como entidades separadas.

un ejemplo tradicional de estructura es el registro de una nómina: un empleado está descrito por un conjunto de atributos, como nombre, domicilio, número del seguro social, salario, etc.

Definamos algunas estructuras propias para graficación. el onjeto básico es un punto, del cual supondremos que tiene una coordenada x y una coordenada y, ambas enteras. Los dos componentes pueden ser colocados en una estructura declarada así:

struct point { int x; int y; };
printf("%d,%d", pt.x, pt.y);

La palabra reservada struct presenta la declaracion de una estructura, que es una lisya de declaraciones entre llaves. Un nombre optativo, llamado rótulo de estructura, puede seguir a la palabra struct (como aqui lo hace point). El rótulo da nombre a esta clase de estructura, y en adelante puede ser utilizado como una abreviatura para la parte de declaraciones entre llaves.

Las variables nombradas dentro de la estructua se llaman miembros. Un miembro de estructura o rótulo, y una variavle ordinario (esto es, no miembro) puede tener el mismo nombre sin conflicto, puesto que siempre se pueden distingir por el contecto. Además, en diferentes estructuras pueden encontrartse los mismos nombres sólo para objetos estrechamente relacionados.

Una declaración struct define un tipo. lallave derecha que termina la lisya de miembros puede ser seguida por una lista de variables, como se hace para cualquier tipo básico. Esto es, struct { ... } x,y,z; es análogo a int x,y,z; en el sentido de que cada proposición declara a x, y y z como una variable del tipo nombrado y causa que se les reserve espacio contiguo.

Una declaración de estructura que no está seguida por una lista de variables no reserva espacio de almacenamiento sino que simplemente describe una plantilla o la forma de una estructura. Sin embargo, si la declaración está rotulada, el rótulo se puede emplear posteriormente en definiciones de isntancias de la estructura.
